Политика обработки персональных данных

Настоящая политика описывает, как обрабатываются персональные данные посетителей демонстрационного сайта-прототипа GEO·AEO агентства.

1. Какие данные собираются

При заполнении форм на сайте (форма заявки на диагностику) могут собираться: имя, email, адрес сайта. Поля «бренд», «ниша», «регион» в форме моделирования видимости используются только для отображения демонстрационного результата в браузере и не передаются на сервер.

2. Цели обработки

Данные используются исключительно для связи с заявителем по поводу запрошенной диагностики и не передаются третьим лицам.

3. Статус прототипа

Этот сайт — демонстрационный прототип. Реальная отправка данных на сервер, хранение и обработка не настроены: форма заявки на этой версии сайта работает в демонстрационном режиме.

4. Согласие

Заполняя форму, пользователь подтверждает согласие на обработку указанных данных для целей, указанных в разделе 2.

5. Контакты

Вопросы по обработке персональных данных можно направить через контактную форму на сайте.
